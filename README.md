# La Patadita de la Suerte — Misión Aguinaldos (DEMO)

Demo web 2D pixel art. Un solo archivo: `index.html` (HTML + CSS + JS, Canvas 2D, Web Audio). No usa backend ni dependencias.

## Ejecutar
- **Local:** abrir `index.html` con doble clic en Chrome, Edge, Safari o Firefox.
- **Web:** activar GitHub Pages en *Settings → Pages → Deploy from a branch*, elegir la rama y la carpeta `/ (root)`.

## Recursos
- Logotipo: `assets/logo-tropicana.png` (suministrado).
- Sprite de Jorge Barón dibujado en código a partir de la fotografía de referencia (traje y camisa blancos de cuello mao, cabello plateado peinado hacia atrás, gran sonrisa, puño en alto).

Controles: ratón/táctil, flechas o WASD. Toda la música es original y se genera con Web Audio. El alias y los resultados se guardan solo en `localStorage`.
